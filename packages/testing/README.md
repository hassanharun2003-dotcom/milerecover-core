# `packages/testing`

Privacy-safe test helpers and synthetic fixtures.

## Allowed (future)

- Synthetic trip generators
- Golden CSV/PDF expected outputs (fake data)
- Mock sync responses
- Test clock utilities

## Prohibited

- Real customer coordinates or routes
- Real calendar or import files
- Imports from `prototypes/` unless promoted
