## Signing-independent simulator build

Local or CI via validation script:

```bash
cd prototypes/native-bridge
npm ci
cd ios
pod install
./scripts/run-simulator-validation.sh
# Windows doc entry: ./scripts/run-simulator-validation.ps1 (delegates to bash on Mac)
```

Manual unsigned build:

```bash
cd prototypes/native-bridge/ios
pod install
xcodebuild \
  -workspace MileRecoverProtoBridgeC.xcworkspace \
  -scheme MileRecoverProtoBridgeC \
  -sdk iphonesimulator \
  -configuration Debug \
  CODE_SIGNING_ALLOWED=NO \
  CODE_SIGNING_REQUIRED=NO \
  build
```
