## Signing-independent simulator build

```bash
cd prototypes/native-bridge
npm ci
cd ios
pod install
xcodebuild \
  -workspace MileRecoverProtoBridgeC.xcworkspace \
  -scheme MileRecoverProtoBridgeC \
  -sdk iphonesimulator \
  -configuration Debug \
  CODE_SIGNING_ALLOWED=NO \
  CODE_SIGNING_REQUIRED=NO \
  build
```
