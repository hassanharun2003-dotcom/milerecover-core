# MileRecover 0.2.0 — 15-minute real-device checklist

Install the standalone preview APK (no Expo Go / no DevLauncher). Clear app data before true first-launch checks.

**APK:** see `docs/CURRENT_PREVIEW_DELIVERY.md`  
**Package:** `com.milerecover.app` · **version:** `0.2.0` · **channel:** `preview`

## Checklist

| # | Check | Pass? |
|---|---|---|
| 1 | Cleared install opens **Welcome** with logo + Get started | ☐ |
| 2 | Complete five stages → Home; Ready matches choices (no “On or ready to confirm”) | ☐ |
| 3 | Force-stop mid-onboarding → resumes correct step | ☐ |
| 4 | After completion, restart → Home (not onboarding) | ☐ |
| 5 | Profile → Review setup edits preferences without erasing trips | ☐ |
| 6 | Preview → Reset app for testing → Welcome again | ☐ |
| 7 | Light theme readable everywhere; no dark theme toggle | ☐ |
| 8 | Protection: Ready for first drive before any auto trip; never Protected prematurely | ☐ |
| 9 | Real short drive, screen off → Review candidate (or honest miss) | ☐ |
| 10 | Standing still / pocket jitter does **not** create ordinary Review drives | ☐ |
| 11 | Samsung battery optimization: captures or single Needs attention repair | ☐ |
| 12 | Force-close + reboot recovery | ☐ |
| 13 | Manual Add drive date/time cancel/confirm stable; 500 km confirms | ☐ |
| 14 | Android Back from supporting screens returns to origin | ☐ |
| 15 | Proof Fix → exact trip field; CSV Free; PDF Plus CTA clear | ☐ |
| 16 | Report share sheet; billing sandbox if available | ☐ |

Treat every fail as a release blocker.
