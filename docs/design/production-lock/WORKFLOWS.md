# Workflows — Production Lock v1.0

Source: Figma `WORKFLOW PROTOTYPE MAP` (`31:22`) + Design Lock board.

Sample amounts in references are **not** production data.

## FRESH USER

```
Welcome
→ Purpose
→ Region & Rate
→ Tracking Education
→ Permission Education
→ Ready
→ Home
```

- No notification permission during this sequence.
- Location is **explained** on Permission Education; OS prompt happens when user chooses Allow (platform-native).

## RETURNING USER

```
Launch
→ Home
```

(Onboarding complete / cleared storage inverted — persistence decides.)

## FIRST DRIVE

```
Home
→ automatic capture OR Add Drive (manual)
→ Review
→ Work / Personal / Not sure
→ Proof reflects confirmed Work
```

## RECOVERY (Missing Drives)

```
Home
→ Missing Drives
→ Scan
→ Candidate results
→ User confirms classification (Work / Personal / Not a drive)
→ Success
→ records update (Home / Review / Proof)
```

Nothing is added without confirmation.

## IMPORT

```
Profile
→ Switch to MileRecover
→ Choose mileage file
→ Detect
→ Preview
→ Resolve issues (if any)
→ Confirm
→ Import
→ Success
```

Competitor names only after factual detection.

## TRACKING FAILURE

```
Home (Needs attention)
→ Fix tracking
→ Protection Center
→ Fix rows (Settings)
→ Healthy
```

## SUBSCRIPTION

```
Free (useful forever)
→ user attempts premium value
→ contextual paywall
→ deliberate Start free 7-day trial OR Continue with Plus
→ Plus / Pro automation
```

Trial **never** auto-starts.

## TRIAL / SUBSCRIPTION EXPIRY

```
Trial or Plus ends
→ user data stays available
→ Free remains usable
→ premium action → contextual paywall
```

History is never held hostage.

## REVIEW REQUEST

```
Positive milestone only
→ Enjoying MileRecover? pre-prompt
→ Rate MileRecover  OR  Not now
```

Never: first launch, onboarding, errors, permission denial, tracking failure, purchase failure, paywall rejection.
